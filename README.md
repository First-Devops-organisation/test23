| API Category           | HTTP Method | Endpoint                                                                                                    | API Version | Purpose                                                                     |
| ---------------------- | ----------- | ----------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------- |
| List Build Definitions | GET         | `https://dev.azure.com/{organization}/{project}/_apis/build/definitions`                                    | 7.1         | Retrieves all pipeline definitions and identifies the pipeline ID by name.  |
| List Builds            | GET         | `https://dev.azure.com/{organization}/{project}/_apis/build/builds?definitions={definitionId}&$top={count}` | 7.1         | Retrieves the most recent builds for the selected pipeline.                 |
| List Build Artifacts   | GET         | `https://dev.azure.com/{organization}/{project}/_apis/build/builds/{buildId}/artifacts`                     | 7.1         | Retrieves metadata and download URLs for artifacts associated with a build. |
| Download Artifact      | GET         | `artifact.resource.downloadUrl`                                                                             | N/A         | Downloads the artifact ZIP file from Azure DevOps.                          |
| Get GitHub Release     | GET         | `https://api.github.com/repos/{owner}/{repo}/releases/tags/{tag}`                                           | 2022-11-28  | Checks whether a release with the specified tag already exists.             |
| Create GitHub Release  | POST        | `https://api.github.com/repos/{owner}/{repo}/releases`                                                      | 2022-11-28  | Creates a new GitHub Release for the migrated build.                        |
| Upload Release Asset   | POST        | `https://uploads.github.com/repos/{owner}/{repo}/releases/{release_id}/assets`                              | 2022-11-28  | Uploads artifact ZIP files as release assets.                               |
| Update Existing Assets | POST        | Same as Upload Release Asset                                                                                | 2022-11-28  | Replaces existing assets when the release already exists.                   |
